# Qwen Code + ApiRouter

## Install Qwen Code

```powershell
npm install -g @qwen-code/qwen-code
```

## Qwen Code config

```text
Base URL: http://localhost:8788/v1
Model: Router
API key: YOUR_APIROUTER_KEY
```

## Without ApiRouter API key

```text
Base URL: http://localhost:8788/v1
Model: Router
API key: any-key
```

## Start Qwen Code

```powershell
qwen
```
